# DupFinder · 本地重复文件清理（macOS）

一个用 **SwiftUI** 原生编写的 macOS 重复文件清理工具，支持**精确去重**与**相似图片检测**两种模式，
全部本地离线运行、零第三方依赖，专为自用设计。

## 两种扫描模式
| 模式 | 原理 | 能找出 |
|---|---|---|
| **精确去重** | SHA-256 内容哈希（渐进式） | 字节完全相同的副本 |
| **相似图片** | Apple Vision 特征 + Accelerate 距离 + 并查集聚类 | 改尺寸、重压缩、换格式、加轻微水印的重复照片 |

## 功能
- 📁 选择任意多个文件夹进行扫描（递归遍历子目录）
- ⚡ **渐进式哈希**：先比 16KB 前缀、再比 1MB，逐级淘汰，最后才全量读取 → **I/O 减少 89%**
- 💾 **哈希缓存**：以 `dev:inode:size:mtime` 为键，二次扫描 **I/O 减少 96%**
- 🔀 **设备感知并发**：外接机械盘自动降并发（多线程会让机械盘寻道抖动反而更慢）
- 🔗 **硬链接识别**：同一 inode 的多个路径只占一份磁盘空间，不会被误报为重复（扫 Time Machine 备份卷必备）
- 📦 **「包」处理开关**：默认跳过 `.app` / `.photoslibrary` / `.framework` 等包内部；可按需开启穿透
- 🖼 **缩略图预览**：图片用 `CGImageSource` 异步生成真缩略图，其他类型显示系统图标
- 🗂 按内容分组展示，组头显示代表文件名、份数、每份大小、可节省空间
- 🔍 **差异对比**：与组内参考文件比较修改日期（差异橙色高亮）、显示图片像素尺寸
- 🛡 **参考文件夹**：标记为「参考」的目录，其中的文件永远不会被删除（防止误删原片）
- ↩️ **⌘Z 撤销**：删除后可一键把文件从废纸篓移回原位
- 👁 **Quick Look 预览**：右键或底部按钮唤起系统预览
- ✅ 勾选删除，支持「每组保留一个」/「相似组保留最佳（体积最大）」
- 🗑 **删除前弹确认框**，显示数量与可释放空间；整组全选、包内文件、相似模式误判风险均会**警示**
- ⛔ **可随时停止扫描**（收集与哈希阶段均有取消点）
- 📊 收集阶段显示已扫描文件数；底部实时显示「已选 N 项 · 可释放 X」
- 🗑 删除一律走**废纸篓**（非永久删除，安全可逆）
- 🚫 自动跳过常见无意义大目录：`node_modules` / `.git` / `Library` / `Caches` / `DerivedData` / `.build`
- ⚠️ 因权限无法读取的项目会被统计并提示，不再静默跳过

> 开发向的架构说明、实测标定数据与待办，见 **HANDOVER.md**。

## 运行方式
> 本机 SwiftPM 编译 manifest 时会被 `sandbox-exec` 拦截（嵌套沙箱不允许），
> 因此统一加 `--disable-sandbox`；这一步已封装进 `build.sh`。

```bash
cd DupFinder
./build.sh            # release 编译并打包 DupFinder.app
open DupFinder.app    # 双击运行，或在 Finder 中双击
./build.sh smoke      # 运行核心逻辑冒烟测试（18 项断言）
```
也可在终端直接跑裸可执行文件：`.build/release/DupFinder`（需处于 GUI 会话）。

最低系统：**macOS 13 (Ventura)**，Apple Silicon / Intel 通用（本机构建为 arm64）。

## 算法

### 精确去重
1. 递归收集所有常规文件（跳过符号链接、隐藏项、常见垃圾目录），记录体积与 inode；
2. **按 inode 去重**：同一 inode 只统计一次，硬链接不计为重复；
3. 按体积分组，体积唯一的文件不可能重复 → 排除；
4. 对「体积出现 ≥2 次」的候选做**渐进式哈希**：先比前 16KB，匹配再比前 1MB，仍匹配才全量读取；
5. 按哈希分组，组内 ≥2 份即判定为重复；按可节省空间降序排列。

全过程在收集与哈希阶段均检查取消标记，可随时中止。

### 相似图片
1. 收集图片文件（按扩展名过滤）；
2. 用 `CGImageSource` 降采样到 256px（不解码整张大图）；
3. Vision 的 `VNGenerateImageFeaturePrintRequest` 提取特征向量；
4. `vDSP_distancesq` 计算两两平方欧氏距离；
5. 距离 < 阈值视为相似，用**并查集**做传递闭包聚类（A≈B、B≈C → 同一组）。

**相似度阈值默认 0.5**（可调 0.1–1.5）。实测标定：
同一张图自比 0.00；缩小 50%+JPEG q50 为 0.34；两张不同的相似照片 0.69–1.02。
注意重度降质（<25% 尺寸或 q30 以下）距离可达 1.44，比两张不同照片还远——
**任何感知哈希都无法可靠识别重度降质的副本**。

## 性能（实测）
60 个 2MB 文件、仅 2 对重复的测试集，**实际读取字节数**：

| 方案 | 读取 | 相比基线 |
|---|---|---|
| 基线（全量哈希） | 120.0 MB | — |
| 渐进式哈希（冷） | 12.9 MB | ↓ 89% |
| 渐进式 + 缓存（二次扫描） | 4.9 MB | ↓ 96% |

> 原计划还要把 SHA-256 换成 BLAKE3，实测后放弃：M4 上 SHA-256 硬件加速达 **2723 MB/s**，
> 瓶颈是磁盘 I/O 而非 CPU，换更快的哈希收益接近于零。

## 安全设计
- 删除一律走 **废纸篓**（`NSWorkspace.recycle`），绝不 `rm` 永久删除
- 删除前必须弹确认框，展示数量与空间；整组全选、或选中项位于包内部时额外红色警示
- **参考文件夹**内的文件无法被勾选删除（需先取消参考标记）
- **⌘Z 可撤销**最近一次删除，把文件从废纸篓移回原位
- 「保留一个」会先把保留项从删除集合中摘除，避免语义反转
- 默认跳过「包」内部，从源头避免误删导致 App 损坏 / 照片库异常
